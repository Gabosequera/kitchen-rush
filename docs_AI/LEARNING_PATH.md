# Learning Path

The project intentionally grows in complexity.

## Stage 1 — Menu foundations

Concepts: variables, strings, functions, return values, simple conditions.

## Stage 2 — Orders

Concepts: lists, dictionaries, mutation, loops, data shape contracts.

## Stage 3 — Inventory

Concepts: validation, iteration, all-or-nothing state changes.

## Stage 4 — Kitchen integration / MVP

Concepts: modules calling other modules, state transitions, integration debugging.

Completing Stage 4 unlocks Shift Mode.

## Stage 5 — Cancellation and reservations

Discovered during Shift Mode.

Concepts: reversible state, transactions, rollback, ownership of mutations.

## Stage 6 — Priority pressure

Concepts: sorting/selection, queue policies, tie-breaking, waiting time.

## Stage 7 — High-volume lookup

Concepts: OOP introduced for a practical reason, data-structure choice, complexity, performance measurement.

## Stage 8 — Persistence

Concepts: JSON, file I/O, serialization boundaries, restart recovery.

After Stage 8, the checker has delivered the planned medium-level curriculum. Future evolution may be driven by the team.
